Anima Mundi

A personal desktop app, built by Miguel Ortiz, an engineering student at Embry-Riddle Aeronautical University.

Anima Mundi is a study and project workspace that runs on its owner's own computer. It keeps track of classes and deadlines, helps plan the week, and helps make documents and slides for school and personal projects.

What it does with Google

When its owner asks, Anima Mundi turns a Word or PowerPoint file it made into a Google Doc or Google Slides file in his own Google Drive, and can apply edits he approves to those files. It only ever sees the files it created itself; it cannot see anything else in the Drive.

It is a personal tool, not a public service: it has no accounts, no server and no other users.
